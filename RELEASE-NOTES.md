2WChat 1.12.0 — улучшенная демонстрация.

- Windows Graphics Capture вместо старого захвата для окон и мониторов. Современный захват используется и в предпросмотре.
- Обрабатываются свежие кадры, накопившиеся устаревшие пропускаются.
- При медленной записи в сетевой канал уменьшается размер JPEG-кадров; при восстановлении скорости качество постепенно возвращается.
- Поддержка изменения размера окна и остановка при закрытии/сворачивании сохранены.

Формат передачи пока остаётся JPEG 5/10 кадров в секунду; H.264 и повышение до 30/60 FPS в эту версию не входят. Защищённое содержимое всё ещё может быть недоступно для захвата.
Требуется Windows 10 версии 2004 (19041) или новее / Windows 11.
Обновление: Сервис → Проверить обновления. Доступен и установщик Setup.exe.
