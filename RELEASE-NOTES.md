2WChat 1.5.0 — автообновление через GitHub Releases.

- Проверка новых выпусков при запуске (не чаще раза в сутки); можно выключить в меню «Сервис».
- Ручная проверка и установка: «Сервис → Проверить обновления».
- Загрузка с прогрессом и отменой, проверка SHA-256 и версии EXE, перезапуск с сохранением профиля.
- Установка доступна после выхода из комнаты. Прежний EXE сохраняется как `2WChat.exe.previous`.
- Сохранены голос, текст, картинки, уведомления и демонстрация экрана версии 1.4.

Для перехода с 1.4 и более ранних версий скачайте этот ZIP и один раз запустите новый 2WChat.exe. Дальнейшие версии можно устанавливать из программы.

Windows x64. Распакуйте архив целиком в доступную для записи папку. Установка .NET не требуется.
