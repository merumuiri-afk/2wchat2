2WChat 1.10.0 — свои стикеры.

Нажмите «Стикеры…» возле поля сообщения (или Сервис → Мои стикеры). Создайте стикер из картинки, проверьте предпросмотр и добавьте в коллекцию. Нажатие на стикер отправляет его в чат.
Можно убрать однотонный фон, связанный с краями картинки. PNG-прозрачность сохраняется; GIF используется как статичный первый кадр. Сложный фон автоматически не вырезается.
Картинку из чата можно добавить через правую кнопку → Добавить в мои стикеры. Удаление из коллекции — правой кнопкой по стикеру.
Коллекция хранится локально в профиле (до 100 стикеров). Получатель видит стикер без предварительной установки. На старых версиях он может отображаться как обычная картинка; для специального вида обновите владельца комнаты и участников.

Обновление: Сервис → Проверить обновления, после выхода из комнаты.
