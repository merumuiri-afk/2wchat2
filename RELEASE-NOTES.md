2WChat 1.6.0 — аватарки участников.

- «Сервис → Моя аватарка»: выбор PNG/JPEG/GIF/BMP, предпросмотр и удаление.
- Аватарки видны в списке участников и рядом с именем в сообщениях.
- Картинка обрезается по центру до 96×96 и сохраняется в профиле.
- Изменения передаются по TLS всем участникам; вошедшие позже получают актуальные аватарки.
- При отсутствии аватарки показывается первая буква имени.
- Для аватарок обновите программу у владельца комнаты и участников до 1.6.

Версия 1.5 может установить это обновление через «Сервис → Проверить обновления». Выйдите из комнаты перед установкой. Для более старых версий скачайте ZIP вручную.

Windows 10/11 x64. Распакуйте архив целиком в доступную для записи папку. Установка .NET не требуется.
