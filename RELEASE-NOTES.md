2WChat 1.11.0 — анимированные стикеры из GIF.

Стикеры → Создать из картинки → выберите GIF. Сохраняются все кадры, задержки, прозрачность и повторение исходника. Анимация работает в предпросмотре и чате; в коллекции — при наведении. GIF из чата тоже можно добавить в стикеры правой кнопкой.
Лимиты: до 512×512, 8 МиБ, 300 кадров и 32 млн пикселей по кадрам. Удаление фона для GIF нужно отключить.
Для отправки обновите владельца комнаты до 1.11. Старые участники с поддержкой GIF получают обычную гифку.

Обновление: Сервис → Проверить обновления, после выхода из комнаты.

Предложить название комнаты теперь можно нажатием на название в синей верхней полосе. Пункт из меню «Сервис» убран.
