# Проверка сборки 1.7.0

* 200 автоматических проверок без аппаратного аудиопрогона пройдены.
* Проверены два различных GIF-кадра, сохранение исходных байтов при подготовке
  и передаче по TLS, переименование текущих клиентов и welcome позднего входа.
* Автономный EXE проходит 39 UI-проверок, включая анимируемый PictureBox
  с полученным GIF и обновление поля/заголовка после принятого названия.
* Последние правки фильтра сохранения GIF и защиты при отключении владельца
  проверены компиляцией и повторным UI smoke. Аппаратный аудиотест не повторялся.

  диалогом. Автоматический UI smoke проверяет применение принятого названия,
  а не нажатие кнопки системного диалога подтверждения.
* Новая GIF-возможность согласуется при подключении; старые клиенты получают
  подпись вместо GIF. Лимиты: 8 МиБ, 300 кадров, 32 млн пикселей по кадрам.
